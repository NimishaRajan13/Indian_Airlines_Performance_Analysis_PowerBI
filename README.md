# Indian_Airlines_Performance_Analysis_PowerBI
📌 Project Overview
An interactive Business Intelligence dashboard built using Microsoft Power BI to analyse and compare the performance of major Indian airlines.

The project transforms airline operational data into meaningful business insights through interactive visualisations, KPI tracking and dynamic filtering.

It enables users to explore passenger traffic, monthly trends, customer ratings, estimated profitability, fuel efficiency and environmental impact across different airlines and routes.

The objective: Turn raw airline data into actionable insights that support data-driven decision-making and performance evaluation.
🎯 Business Objectives
- Compare the operational performance of major Indian airlines.
- Analyse passenger traffic and passenger capacity.
- Identify monthly passenger trends and fluctuations.
- Evaluate customer satisfaction through airline ratings.
- Compare estimated profitability across airlines.
- Examine fuel efficiency and CO₂ emissions per passenger.
- Enable interactive analysis using airline, route and destination filters.
